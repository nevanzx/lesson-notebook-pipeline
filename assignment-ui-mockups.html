Assignment UI — 4 concepts same flow · same behavior · token-only

Resize the preview: the frame is a CSS container, so each concept reflows live.

1 · Quiet cards

Calm and bordered. Everything is a soft white card; the accent appears only where it matters (status, selected option, primary action).

2 · Command bar

Puts progress and identity in a coloured band up top, so a student always knows where they are. Options become pill rows; the footer primary stretches.

3 · Split panel

On wide screens a meta rail sits beside the question (title, position, layer trail); on phone and tablet the rail collapses to a slim strip.

4 · Focus minimal

No boxes, no buttons-as-blobs. Type, whitespace and hairline rules carry it; selection is an accent underline plus a check. The quietest option.
