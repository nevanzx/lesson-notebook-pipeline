# milo-list
Click-to-tick list of the lesson's measurable intended learning outcomes, with an SVG progress ring.
Use in Section 0 ("Overview & Outcomes") so students claim what they intend to learn.
Static content stays printable; the ring degrades gracefully in print.

Data (`LN.data.milo0 = ...`):
```js
{ title: optional, items: [{ t: "explain the break-even formula", note: optional }, "or a bare string"] }
```
